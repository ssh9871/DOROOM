# 무한 모드 설계 (v2 초안)

> 규칙 상수: `client/src/game/endless.ts` (`ENDLESS`) · 서버 검증: `server/src/services/gameService.js` (`ENDLESS_RULE`)
> 두 파일의 `zoneSeconds`, `zoneClearBonus` 는 항상 같은 값으로 유지한다.

## 1. 구역 순환

| 회차 | 구역 1 (사파리) | 구역 2 (숲) | 구역 3 (정비) | 구역 4 (허브) |
|---|---|---|---|---|
| 1회차 | 1-3 편성 | 2-3 편성 | 3-3 편성 | 4-1 편성 |
| 2회차 | 1-1 | 2-1 | 3-1 | 4-2 |
| 3회차 | 1-2 | 2-2 | 3-2 | 4-3 |
| 4회차~ | 1회차부터 반복 | | | |

- 배경은 구역 번호로 정해지므로 항상 `1 → 2 → 3 → 4 → 1 → …` 순서.
- 구역이 바뀔 때 배경을 1.5초 크로스페이드하고, 화면 상단에 3초간 안내를 띄운다.
- 생존 시간·정화 수·점수는 구역이 바뀌어도 이어진다.

## 2. 구역 한 개의 흐름

| 시각(구역 진입 기준) | 일 |
|---|---|
| 0초~ | 일반 웨이브 |
| 25 / 50 / 75초 | 엘리트 등장 (처치 시 HP 물약) |
| 90초 (1분 30초) | 보스 등장, 기존 적·탄 정리 |
| 보스 등장 +20초 | 보스가 일반 적 2기 호출 |
| 보스 정화 | 구역 보너스 `50 × 구역번호` 점 → 다음 구역 |

- **보스를 정화해야만 다음 구역으로 넘어간다.** 보스전에는 제한 시간이 없다 (HP 0이 되면 귀환).

## 3. 난이도 곡선

`level = 지나온 구역 수 + (구역 안 경과 시간 / 90초, 최대 1)` 로 연속 상승. 회차가 바뀌어도 리셋되지 않는다.

| level | 공격 빈도 | 탄속 | 웨이브 간격 | 적 체력 | 탄 상한 |
|---|---|---|---|---|---|
| 0 (시작) | 0.80 | 0.85 | 2.1초 | ×1.00 | 90 |
| 4 (1회차 끝) | 1.00 | 0.97 | 1.7초 | ×1.60 | 130 |
| 8 (2회차 끝) | 1.20 | 1.09 | 1.3초 | ×2.20 | 170 |
| 14 이후 | 1.50(상한) | 1.25(상한) | 0.9초(하한) | ×3.10 → 최대 ×5 | 180(상한) |

시작값은 스토리 마지막 지점 4-3(공격 빈도 81%, 탄속 85.4%)에 맞춰서 해금 직후 난이도가 갑자기 튀지 않게 했다.
보스 체력은 `(375 + 138 × 구역) × (1 + 0.15 × 지나온 구역 수)`.

## 4. 점수

`최종 점수 = 생존 초 × 10 + 정화 수 × 5 + Σ 구역 보너스(50 × (k+1))`

- 클라이언트는 보스를 정화한 구역 번호 목록 `clearedAreas`(0부터)를 `/game/:id/finish` 에 보낸다.
- 서버는 점수를 직접 다시 계산하고, `clearedAreas` 가 **오름차순·중복 없음·생존 시간으로 도달 가능**(구역 k 보스는 최소 `(k+1) × 90초` 이후)한지 검증한다.
- DB 스키마 변경은 없다 (`game_run.score` 에 보너스가 포함되어 저장됨).
