# 도로랜드: 펫 정화 작전 — 미니게임 기능 기획서

2026-11-12 · 개발 검토용 초안

기본 화면은 **1280×720**, 지원 환경은 **PC 브라우저**다. 미니게임 메인에서 **게임 시작**, **능력치 강화**, **펫 설정**, **랭킹**을 선택한다. 스테이지 모드는 **4개 작전 지도 × 지도별 입장 지점 3개 = 총 12개 소스테이지**로 구성한다. 각 소스테이지에서 10분간 전투한 뒤 등장하는 보스를 정화하면 클리어한다. 무한 모드는 `4-3` 첫 클리어로 해금되며, 해금 후에는 모드 선택 즉시 전투에 입장한다. 점수 배점, 셀 지급량·비용, 적 이름과 패턴은 플레이테스트용 초안이다.

## 1. 이야기와 작전 구조

도로랜드 재개장 후, 오래된 제어 기록이 새 운영 명령과 충돌하며 보조 기계가 오작동한다. 보이드는 오류 구역을 지도에 표시하고, 펫은 현장의 진동과 움직임에 반응해 정화 타이밍을 포착한다. 플레이어는 정화 호버보드를 타고 낮게 떠서 탄막을 피하며, 보드 앞쪽의 발사구에서 정화 펄스를 쏴 기계를 정상 상태로 돌린다. 펫은 소형 부유 발판을 타고 곁에서 따라간다. 네 작전을 통해 오래된 동기화 장치가 반복 송신의 원인임을 밝혀낸다. 무한 모드는 사건 이후 남은 오류와 새 운용 오류를 확인하는 정기 출동이다. 작전 지도는 순서대로 **낯선 순찰**, **어긋난 숲의 박자**, **되풀이되는 명령**, **마지막 동기화**다. 보스 이름은 각 지점의 전투 목표다. 각 작전의 마지막 지점에서 구역 단서를 확정하고, `4-3` 첫 클리어 결과에서 결말을 보여준다.

## 2. 화면 흐름과 조작

```text
DOROBUS → 미니게임 메인
  ├─ 게임 시작 → 모드 선택
  │    ├─ 스테이지 모드 → 작전 지도 → 입장 지점 선택 → 스토리 소개 → 입장 → 시작 대화 → 전투
  │    └─ 무한 모드(4-3 클리어 후) → 전투
  ├─ 능력치 강화 → 항목 선택 → 효과·비용 확인 → 강화
  ├─ 펫 설정 → 보유 펫 선택 → 장착 또는 장비 칸 선택 → 보유 장비 선택
  └─ 랭킹 → 이번 주 무한 모드 순위
전투 → 종료 대화(스테이지 모드) → 결과 → 다시 도전 / 지도(스테이지 모드) / 메인
```

| 화면 | 표시 및 동작 |
| --- | --- |
| 미니게임 메인 | 게임 시작, 능력치 강화, 펫 설정, 랭킹과 DOROBUS 복귀 버튼을 표시한다. |
| 모드 선택 | 두 모드의 목표를 표시한다. `4-3` 클리어 전에는 무한 모드의 잠금과 해금 조건을 보여준다. 해금 후 버튼을 누르면 즉시 출동한다. |
| 작전 지도 | 작전 1~4를 전환한다. 처음에는 `1-1`만 입장 가능하다. 직전 지점을 클리어하면 다음 지점이 열리며, 작전 경계에서도 순서를 유지한다. 이미 클리어한 지점은 재도전할 수 있다. 잠긴 지점에는 선행 클리어 조건을 표시한다. |

| 스테이지 대화 | 입장 후 시작 대화를 표시한다. `1-1`은 그 뒤에 조작 안내를 연다. 보스 정화 후 지점별 클리어 대화를, HP 0으로 귀환할 때는 공용 귀환 대사를 표시한다. 이름·초상·대사를 한 줄씩 진행한다. [지점별 대사 초안](#10-스테이지-시작과-종료-대화) |
| 전투 | 중앙에 기존 **480×720** 종스크롤 영역을 두고 양쪽에 400px씩 확보한다. 왼쪽에 모드·지점·경과 시간·현재 점수·최고 점수, 오른쪽에 현재/최대 HP, 펫 스킬 상태와 `Esc` 안내를 표시한다. 보스 체력과 등장 경고는 전투 영역 상단에 표시한다. 작은 뷰포트에서 비율을 유지하며 축소한다. |
| 결과 | 클리어·귀환·중단, 실제 생존 시간, 점수 내역, 정화 수, 점수 보상과 클리어 보상, 새로 열린 지점을 표시한다. 다시 도전은 같은 모드·지점으로 입장한다. `4-3` 첫 클리어에는 결말과 무한 모드 출동 버튼을 함께 표시한다. |
| 랭킹 | 이번 주 무한 모드의 순위·닉네임·점수와 집계 기간을 표시한다. 무한 모드를 해금하기 전에도 볼 수 있다. |

PC 조작은 방향키/WASD 이동, 자동 발사, `Shift` 정밀 이동, `E` 또는 HUD 버튼으로 펫 스킬을 사용한다. 수동 일시정지와 키보드 재개는 `Esc`로만 조작한다. 일시정지 메뉴는 계속하기와 출동 중단을 제공한다. 모달을 닫으면 호출 버튼으로, 전투 진입 및 재개 시에는 전투 영역으로 포커스를 돌려준다.

### `1-1` 조작 튜토리얼

`1-1` 시작 대화가 끝나면 제로의 조작 안내를 띄운다. 호버보드 이동·정밀 이동·자동 발사·펫 스킬·`Esc` 일시정지를 안내하고, HP 표시와 엘리트가 떨어뜨리는 물약을 설명한다. 플레이어가 `전투 시작`을 누르면 안내를 닫고 적 소환과 10분 타이머를 시작한다. 재도전에서도 같은 화면에서 바로 전투를 시작할 수 있다.

## 3. 전투 규칙

### 호버보드 이동과 펫 동행

- 플레이어는 호버보드를 타고 전투 영역 안에서 상하좌우와 대각선으로 이동한다. 보드 앞쪽과 정화 펄스는 화면 위를 향한다. 좌우 입력에는 탑승자와 보드가 함께 기울고, `Shift` 정밀 이동 중에는 속도를 낮추고 추진광을 짧게 표시한다. 입력을 놓으면 화면 안 현재 위치에 떠 있고 배경은 계속 아래로 흐른다.
- 펫은 소형 부유 발판 위에서 플레이어의 왼쪽 뒤를 부드럽게 따라간다. 펫과 발판은 함께 살짝 위아래로 움직이고, 스킬 발동 시 펫의 자세와 이펙트가 바뀐다. 펫 이동은 자동으로 처리한다.
- 호버보드의 기울기와 추진광은 시각 연출이다. 플레이어의 피격 중심은 자세가 바뀌어도 같은 상대 위치에 유지한다.

### 스테이지 모드

| 경과 시간 | 진행 |
| --- | --- |
| `0:00` | 해당 지점의 일반 적 웨이브 시작 |
| `2:00`, `4:00`, `6:00`, `8:00` | 각 시점에 엘리트 1기 등장. 예정 시점 직전에 경고를 표시한다. |
| `10:00` | 보스 1기만 등장. 일반 웨이브 및 엘리트 추가 생성 종료, 남은 적과 적 탄환 정리 후 보스 전투 시작 |
| 보스 정화 | 즉시 클리어 및 결과 표시. 첫 클리어면 다음 입장 지점 해금 |
| HP 0 | 즉시 귀환 및 실패 결과 표시 |

10분은 보스가 나오기까지의 전투 시간이다. 보스전에서도 실제 경과 시간은 기록하되 생존 시간 점수는 10분 시점에 고정한다. 일시정지 중에는 경과 시간, 소환 일정, 물약 이동과 스킬 지속 시간·재사용 시간이 함께 멈춘다. 동일 전투 갱신에서 HP 0과 보스 정화가 함께 발생하면 클리어 우선으로 처리하는 안을 적용한다.

### 무한 모드

- `4-3` 클리어 후 모드 선택 즉시 정기 출동으로 시작한다.
- 초기 배경은 사파리다. 각 구역 진입 후 2·4·6·8분에 엘리트, 10분에 구역 보스가 등장한다. 보스전 동안 구역의 추가 소환을 멈추고, 정화하면 다음 구역의 소환 일정을 0분부터 시작한다. 누적 생존 시간은 이어진다. 네 구역을 순환하며 허브에서는 허브 경비기 계열을 보스로 쓴다. 구역 전환 시 남은 적 탄환을 정리한다.
- 진행에 따라 적 체력, 조합, 탄막 밀도를 조정한다. 화면 내 적·탄환 수와 발사 빈도는 성능과 회피 가능성을 기준으로 상한을 둔다. HP가 0이 되면 출동이 끝나고 이번 주 랭킹 집계 대상이 된다.

### HP와 회복

- 생존 상태는 HP 하나로 관리한다. 기본 최대 HP는 **5**이며 매 판 강화가 반영된 최대 HP로 시작한다. 일반 피격은 1 HP를 차감하고 기존 피격 후 무적 시간 2초를 적용한다.
- 두 모드에서 엘리트를 정화하면 그 자리에 물약 1개를 떨어뜨린다. 물약은 아래로 이동하며 플레이어가 닿으면 소모되어 **1 HP**를 회복한다. 최대 HP에서 닿으면 물약만 소모되고, 화면 아래를 벗어난 물약은 제거한다.
- 회복 수단은 물약과 펫의 체력 회복 스킬이다. 둘 다 최대 HP까지만 1 HP를 회복한다. HP가 0이면 전투를 종료한다.

### 점수와 셀 보상 초안

| 항목 | 계산식 및 규칙 |
| --- | --- |
| 생존 시간 점수 | 전투 1초당 1점, 초 단위 내림. 스테이지 모드는 최대 600점, 무한 모드는 실제 전투 시간 전체를 반영한다. 조작 안내와 일시정지 시간은 전투 시간에서 제외한다. |
| 정화 점수 | 일반 적·엘리트·보스 모두 정화 1기당 10점. 보스 등장 시 정리되거나 화면 밖으로 이탈한 적은 정화 수에서 제외한다. 보스전 중 실제 정화는 점수에 포함한다. |
| 최종 점수 | `생존 시간 점수 + 정화 점수` |
| 점수 보상 | `최종 점수 ÷ 25`를 내림한 셀. 스테이지 실패·클리어 및 무한 모드의 정상 종료에 지급한다. |
| 스테이지 클리어 보상 | 각 지점의 보스를 정화할 때마다 아래 고정 보상을 점수 보상에 더한다. |
| 출동 중단 | 중단으로 표시한다. 보상 지급과 랭킹 등록 대상에서 제외한다. |

| 작전 | 첫 번째 지점 | 두 번째 지점 | 세 번째 지점 |
| --- | ---: | ---: | ---: |
| 작전 1 | `1-1` 40셀 | `1-2` 50셀 | `1-3` 60셀 |
| 작전 2 | `2-1` 70셀 | `2-2` 80셀 | `2-3` 90셀 |
| 작전 3 | `3-1` 100셀 | `3-2` 110셀 | `3-3` 120셀 |
| 작전 4 | `4-1` 130셀 | `4-2` 140셀 | `4-3` 150셀 |

- `1-1`에서 5분 동안 50기를 정화하고 실패하면 `300 + 500 = 800점`으로 **32셀**을 받는다.
- `1-1`에서 보스를 포함해 110기를 정화하고 11분에 클리어하면 `600 + 1,100 = 1,700점`이다. 점수 보상 68셀과 클리어 보상 40셀로 **108셀**을 받는다.

## 4. 능력치 강화

뱀파이어 서바이버즈의 출전 전 강화 화면을 시각적 참고로 삼는다. 왼쪽은 항목 카드 그리드, 오른쪽은 선택한 항목의 설명과 구매 영역으로 구성한다. 카드에 아이콘·이름·현재 단계·최대 단계를 표시하고 상세 영역에 **현재 효과 → 다음 단계 효과**, 비용, 보유 재화, 강화 버튼을 표시한다. 잔액 부족, 최대 단계, 저장 실패를 구분해서 표시한다. 카드 개수가 늘어나면 그리드 안에서 스크롤한다.

| 항목 | 전투 효과와 단계 | 단계별 비용 초안 (셀) |
| --- | --- | --- |
| 발사체 개수 | 기본 1발, 단계당 +1발, 최대 2단계. 플레이어 중심 기준 좌우 대칭 배치 | 120 / 300 |
| 피해량 | 정화 펄스 1발의 피해량이 기본 대비 단계당 +10%, 최대 5단계 | 60 / 100 / 150 / 220 / 320 |
| 발사체 크기 | 표시와 충돌 범위가 기본 대비 단계당 +10%, 최대 5단계 | 50 / 80 / 120 / 180 / 260 |
| 체력 | 기본 최대 5 HP, 단계당 +1 HP, 최대 3단계 | 80 / 150 / 280 |

강화는 셀을 소모하며 다음 출동부터 두 모드에 적용한다. 성공 시 셀 잔액과 단계를 함께 갱신한다. 항목마다 ID·이름·아이콘·설명·단계별 효과와 비용을 정의해 UI에서 동일한 카드로 표시한다. 새 효과는 전투 쪽 적용 규칙을 추가한다.

## 5. 펫 설정과 스킬

1. 보유 펫 목록을 표시하고 현재 출전 펫을 강조한다. DB 연동 전에는 기존 클라이언트 펫 데이터를 사용한다. 연동 후에는 DB에 저장된 로그인 유저의 보유 펫을 목록에 표시한다.
2. 펫을 클릭하면 상세에 이름·이미지·고유 스킬 효과·쿨타임, `장착` 버튼과 펫 장비 칸이 표시된다. 목록에서 살펴보는 펫과 출전 펫은 별도 상태다. `장착`을 누르면 출전 펫 한 마리를 교체하고 저장한다.
3. 장비 칸을 누르면 해당 슬롯과 호환되는 보유 장비를 표시한다. 장비 선택 시 효과를 미리 보여주고, `장착` 또는 `해제`를 누르면 그 펫의 슬롯을 갱신한다. 장비가 없으면 빈 상태를 표시한다. 초안은 펫당 슬롯 1개, 장비 1개를 동시에 한 펫에만 장착하는 규칙이다. 장비 교체 규칙과 획득처는 확정 후 적용한다.
4. 입장 시 출전 펫·장비·강화 단계의 전투 값을 확정한다. 스킬 버튼은 준비·효과 적용 중·재사용 대기 상태와 남은 시간을 표시한다. 모든 스킬의 재사용 대기 시간은 **60초**이며 성공적으로 발동한 시점부터 흐른다.

| 고유 스킬 | 적용 범위 | 프로토타입 수치 |
| --- | --- | --- |
| 보호막 | 짧은 시간 플레이어 피격을 막는다. 기존 보호막 동작을 재사용한다. | 3초 지속 |
| 전체 탄환 지우기 | 발동 순간 전투 영역 내 적 탄환을 즉시 제거한다. 이후 탄환은 계속 생성된다. | 즉시 |
| 체력 회복 | 현재 HP를 즉시 회복한다. 체력이 가득 차 있으면 발동과 재사용 대기 모두 시작하지 않는다. | 1 HP |
| 공격속도 증가 | 일정 시간 자동 발사 빈도를 증가시킨다. | +30%, 5초 지속 |

펫 데이터가 고유 스킬 ID를 가리키게 하고, 공통 HUD는 스킬 이름·아이콘·시간 상태를 읽어 표시한다. 이후 펫과 스킬을 추가할 때 기존 선택 화면을 재사용한다. 네 가지 스킬을 어떤 펫에 배정할지와 장비가 스킬·전투 수치 중 어디에 영향을 줄지는 별도 결정한다.

## 6. 저장과 주간 랭킹

| 데이터 | 초기 클라이언트 저장 | DB 연동 후 |
| --- | --- | --- |
| 보유 펫·출전 설정 | 기존 펫 데이터와 로컬 장착 상태를 사용한다. | 보유 펫 목록을 로그인 유저의 DB 데이터에서 조회한다. 장착·장비의 계정 저장 범위는 별도로 정한다. |
| 강화·셀·스테이지 진행 | 강화는 항목 ID별 단계로 저장한다. 셀 잔액, 클리어한 지점, 지점별 최고 점수도 로컬에 기록한다. | 강화·진행 저장은 우선 로컬에 둔다. 향후 이전을 위해 저장 데이터에 버전을 두고 화면과 전투는 저장 위치에 직접 의존하지 않게 한다. |
| 무한 모드 결과 | 현재 브라우저의 무한 모드 기록으로 이번 주 순위를 미리 확인한다. 화면에 `이 브라우저의 기록`으로 표시한다. | 정상 종료한 무한 모드 점수를 DB에 기록한다. 필수 정보는 출동 ID, 유저 ID, 점수, 서버가 기록한 완료 시각이다. 닉네임은 유저 정보에서 조회한다. |

- **조회.** 메인에서 `랭킹`을 열면 초기에는 로컬 기록을 읽고, DB 연동 후에는 서버에 이번 주 무한 모드 기록을 요청한다. 점수 내림차순으로 표시한다. 초안은 유저별 주간 최고 점수 한 건을 집계하며 동점이면 먼저 달성한 기록을 위에 표시한다. 이번 주 기록이 없으면 빈 상태를 표시한다.
- **주간 초기화.** 초안 기준은 한국시간 월요일 `00:00`부터 다음 월요일 `00:00` 직전까지다. 출동을 끝낸 시각으로 집계 주를 정한다. 새 주에는 이전 주 기록이 순위에서 빠진다. 초기에는 클라이언트 시각, DB 연동 후에는 서버 시각을 사용한다.
- **결과 저장.** 출동 ID별로 결과와 셀 보상을 한 번만 반영한다. DB 전환 시에는 검증 가능한 새 출동부터 공용 랭킹에 집계한다. 서버의 결과 검증 방식과 계정 간 동기화 범위는 연동 단계에서 확정한다.

### 제작 순서와 산출물

1. **`1-1` 시안.** 사파리 지도와 전투 배경, 제로·보이드 초상, 호버보드 탑승자와 추진광, 고양이와 부유 발판, 순찰기·엘리트·선두 순찰기, 기본 탄환과 물약을 먼저 그린다. 탑승자와 펫의 부유 이동을 확인한 뒤 체력·경고·보호막 아이콘과 효과를 붙여 시작 대화부터 결과까지 연결한다.
2. **전체 구역과 공용 UI.** 리코·자일로·코덱스 초상과 네이티의 상태별 스프라이트, 나머지 지도와 배경, 지점별 오브젝트, 적·보스 변형과 전용 이펙트, 메뉴·강화·스킬 아이콘과 공용 장비 아이콘을 제작한다. 구역이 달라져도 탄환, 물약, 플레이어의 피격 중심을 즉시 찾을 수 있는지 확인한다.
3. **원본과 게임 파일 내보내기.** 제작 원본은 `art/minigame/`에 `.aseprite`로 보관하고, 게임에서 쓰는 파일은 `client/public/assets/minigame/`에 둔다. 정적 이미지는 PNG, 애니메이션은 투명 PNG 스프라이트 시트와 Aseprite JSON으로 내보낸다. 프레임 태그는 용도에 맞춰 `idle`, `move`, `attack`, `cast`, `purified` 등을 사용하고 애니메이션 프레임의 기준점을 고정한다. 파일명에는 `map-01`, `boss-1-1`, `pet-cat-001`, `fx-shield`처럼 게임에서 찾기 쉬운 ID를 사용한다.

완료 기준은 1280×720 화면에서 도트 가장자리가 흐려지지 않고, 종스크롤 배경의 반복 경계가 보이지 않으며, 탄환·물약·경고를 색과 형태로 구별할 수 있는 상태다.

## 10. 스테이지 시작과 종료 대화

아래는 스토리 프레임워크의 역할을 반영한 게임용 임시 대사다. 한 줄에 화자 한 명을 표시한다. 보이드의 문구는 단말 메시지로 표시하고, 네이티와 동행 펫은 표정·빛·움직임으로 반응한다. 동행 펫의 반응 연출은 현재 출전 펫 스프라이트를 사용한다. [인물 배치 프레임워크](./doroland-minigame-story-framework.md#10-등장인물-배치-프레임워크)

- **시작 대화.** 지도에서 `입장`을 누른 직후 표시한다. 마지막 대사를 넘기면 전투를 시작하고, `1-1`은 먼저 조작 안내로 넘어간다. 전투 시간은 적 소환이 시작될 때부터 계산한다.
- **클리어 대화.** 보스 정화 순간에 전투와 점수 산정을 끝내고, 마지막 대사 뒤에 결과 화면을 연다. `4-3`의 클리어 대화가 사건의 결말을 맡고, 첫 클리어 결과에서 무한 모드 해금을 안내한다.
- **귀환과 재도전.** HP가 0이면 보이드 단말에 “위험 한계 도달. 자동 귀환을 시작합니다.”를 띄운 뒤 실패 결과를 표시한다. 중단 시에는 바로 중단 결과를 표시한다. 재도전에서는 시작·종료 대화를 다시 보거나 `건너뛰기`로 넘길 수 있다.
