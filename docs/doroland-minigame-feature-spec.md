# 도로랜드: 펫 정화 작전 — 미니게임 기능 기획서

2026-11-12 · 개발 검토용 초안

기본 화면은 **1280×720**, 지원 환경은 **PC 브라우저**다. 미니게임 메인에서 **게임 시작**, **능력치 강화**, **펫 설정**, **랭킹**을 선택한다. 스테이지 모드는 **4개 작전 지도 × 지도별 입장 지점 3개 = 총 12개 소스테이지**로 구성한다. 각 소스테이지는 5분까지 일반 웨이브를 진행하고, 이어서 등장하는 보스를 정화하면 클리어한다. 무한 모드는 `4-3` 첫 클리어로 해금되며, 해금 후에는 모드 선택 즉시 전투에 입장한다. 점수 배점, 셀 지급량·비용, 적 이름과 패턴은 플레이테스트용 초안이다.

## 1. 이야기와 작전 구조

도로랜드 재개장 후, 오래된 제어 기록이 새 운영 명령과 충돌하며 보조 기계가 오작동한다. 보이드는 오류 구역을 지도에 표시하고, 펫은 현장의 진동과 움직임에 반응해 정화 타이밍을 포착한다. 플레이어는 정화 호버보드를 타고 낮게 떠서 탄막을 피하며, 보드 앞쪽의 발사구에서 정화 펄스를 쏴 기계를 정상 상태로 돌린다. 펫은 소형 부유 발판을 타고 곁에서 따라간다. 네 작전을 통해 오래된 동기화 장치가 반복 송신의 원인임을 밝혀낸다. 무한 모드는 사건 이후 남은 오류와 새 운용 오류를 확인하는 정기 출동이다. [미니게임 스토리 프레임워크](./doroland-minigame-story-framework.md)

| 지점 | 입장 전 소개 문구 초안 | 5분 보스 · 정화 결과 |
| --- | --- | --- |
| 1-1 외곽 순찰로 | 제로가 사파리 입구에서 같은 길을 도는 순찰기를 발견했다. 펫과 함께 안전 통로를 확보하자. | 선두 순찰기 · 통로 확보 |
| 1-2 관리 초원 | 초원의 순찰기들이 같은 시각에 방향을 바꾼다. 보이드가 공통 명령을 추적한다. | 초원 경비기 · 명령 시간대 확보 |

| 3-1 관람차 정비로 | 방금 정화한 기계가 다시 움직인다. 자일로가 관람차 아래의 정비 기록을 공개했다. | 정비 지휘기 · 반복 수신 로그 확보 |
| 3-2 자재 이송장 | 운반 라인에서 증원 신호가 계속 발신된다. 발신기를 정화해 이송장을 확보하자. | 증원 중계기 · 신호 발신 경로 확인 |
| 3-3 크레인 작업장 | 리코가 작업장 안쪽에서 동일한 신호를 찾았다. 크레인이 보낸 마지막 기록에 원점이 남아 있다. | 운반 크레인 · 옛 동기화 장치 위치 특정 |
| 4-1 허브 진입로 | 보이드가 보조 제어 허브의 입구를 표시했다. 기존 구역의 기계들이 한곳에 모이고 있다. | 허브 경비기 · 진입로 확보 |
| 4-2 송신 제어실 | 리코와 자일로가 송신 차단을 준비한다. 그동안 제어실의 중계기를 안정시켜야 한다. | 이중 송신기 · 보조 송신 차단 |
| 4-3 중앙 동기화실 | 중앙 장치가 방어 기계에 같은 명령을 보내고 있다. 펫과 함께 마지막 방어기를 정화하자. | 중앙 장치 방어기 · 반복 송신 종료 및 엔딩 |

작전 지도는 순서대로 **낯선 순찰**, **어긋난 숲의 박자**, **되풀이되는 명령**, **마지막 동기화**다. 보스 이름은 각 지점의 전투 목표다. 전투 구성은 [스테이지별 패턴 배치](#스테이지별-패턴-배치)를 따른다. 각 작전의 마지막 지점에서 구역 단서를 확정하고, `4-3` 첫 클리어 결과에서 결말을 보여준다.

## 2. 화면 흐름과 조작

```text
DOROBUS → 미니게임 메인
  ├─ 게임 시작 → 모드 선택
  │    ├─ 스테이지 모드 → 작전 지도 → 입장 지점 선택 → 스토리 소개 → 입장 → 시작 대화 → 전투
  │    └─ 무한 모드(4-3 클리어 후) → 전투
  ├─ 능력치 강화 → 항목 선택 → 효과·비용 확인 → 강화
  ├─ 펫 설정 → 보유 펫 선택 → 장착 또는 장비 칸 선택 → 보유 장비 선택
  └─ 랭킹 → 이번 주 무한 모드 순위
전투 → 종료 대화(스테이지 모드) → 결과 → 다시 도전 / 지도(스테이지 모드) / 메인
```

| 화면 | 표시 및 동작 |
| --- | --- |
| 미니게임 메인 | 게임 시작, 능력치 강화, 펫 설정, 랭킹과 DOROBUS 복귀 버튼을 표시한다. |
| 모드 선택 | 두 모드의 목표를 표시한다. `4-3` 클리어 전에는 무한 모드의 잠금과 해금 조건을 보여준다. 해금 후 버튼을 누르면 즉시 출동한다. |
| 작전 지도 | 작전 1~4를 전환한다. 처음에는 `1-1`만 입장 가능하다. 직전 지점을 클리어하면 다음 지점이 열리며, 작전 경계에서도 순서를 유지한다. 이미 클리어한 지점은 재도전할 수 있다. 잠긴 지점에는 선행 클리어 조건을 표시한다. |
| 스토리 소개 | 번호·이름, 소개 1~2문장, 작전 목표와 예상 시간, 입장 버튼을 표시한다. 닫으면 방금 보던 지도와 지점으로 돌아간다. |
| 스테이지 대화 | 입장 후 시작 대화를 표시한다. `1-1`은 그 뒤에 조작 안내를 연다. 보스 정화 후 지점별 클리어 대화를, HP 0으로 귀환할 때는 공용 귀환 대사를 표시한다. 이름·초상·대사를 한 줄씩 진행한다. [지점별 대사 초안](#10-스테이지-시작과-종료-대화) |
| 전투 | 중앙에 기존 **480×720** 종스크롤 영역을 두고 양쪽에 400px씩 확보한다. 왼쪽에 모드·지점·경과 시간·현재 점수·최고 점수, 오른쪽에 현재/최대 HP, 펫 스킬 상태와 `Esc` 안내를 표시한다. 보스 체력, 보스 정화 제한 시간, 등장 경고는 전투 영역 상단에 표시한다. 전투 중 좌우 HUD의 빈 곳을 클릭해도 이동 키를 계속 사용할 수 있다. 작은 뷰포트에서 비율을 유지하며 축소한다. |
| 결과 | 클리어·귀환·중단, 실제 생존 시간, 점수 내역, 정화 수, 점수 보상과 클리어 보상, 새로 열린 지점을 표시한다. 다시 도전은 같은 모드·지점으로 입장한다. `4-3` 첫 클리어에는 결말과 무한 모드 출동 버튼을 함께 표시한다. |
| 랭킹 | 이번 주 무한 모드의 순위·닉네임·점수와 집계 기간을 표시한다. 무한 모드를 해금하기 전에도 볼 수 있다. |

PC 조작은 방향키/WASD 이동, 자동 발사, `Shift` 정밀 이동, `E` 또는 HUD 버튼으로 펫 스킬을 사용한다. 수동 일시정지와 키보드 재개는 `Esc`로만 조작한다. 일시정지 메뉴는 계속하기와 출동 중단을 제공한다. 모달을 닫으면 호출 버튼으로, 전투 진입 및 재개 시에는 전투 영역으로 포커스를 돌려준다.

### `1-1` 조작 튜토리얼

`1-1` 시작 대화가 끝나면 제로의 조작 안내를 띄운다. 호버보드 이동·정밀 이동·자동 발사·펫 스킬·`Esc` 일시정지를 안내하고, HP 표시와 엘리트가 떨어뜨리는 물약을 설명한다. 플레이어가 `전투 시작`을 누르면 안내를 닫고 적 소환과 전투 타이머를 시작한다. 재도전에서도 같은 화면에서 바로 전투를 시작할 수 있다. 탄막 대응은 전투에서 탄의 방향과 발사 간격을 보며 익힌다.

## 3. 전투 규칙

### 호버보드 이동과 펫 동행

- 플레이어는 호버보드를 타고 전투 영역 안에서 상하좌우와 대각선으로 이동한다. 보드 앞쪽과 정화 펄스는 화면 위를 향한다. 좌우 입력에는 탑승자와 보드가 함께 기울고, `Shift` 정밀 이동 중에는 속도를 낮추고 추진광을 짧게 표시한다. 입력을 놓으면 화면 안 현재 위치에 떠 있고 배경은 계속 아래로 흐른다.
- 펫은 소형 부유 발판 위에서 플레이어의 왼쪽 뒤를 부드럽게 따라간다. 펫과 발판은 함께 살짝 위아래로 움직이고, 스킬 발동 시 펫의 자세와 이펙트가 바뀐다. 펫 이동은 자동으로 처리한다.
- 호버보드의 기울기와 추진광은 시각 연출이다. 플레이어의 피격 중심은 자세가 바뀌어도 같은 상대 위치에 유지한다.

### 스테이지 모드

| 경과 시간 | 진행 |
| --- | --- |
| `0:00` | 해당 지점의 일반 적 웨이브 시작 |
| `1:00`, `2:00`, `3:00`, `4:00` | 매분 엘리트 1기 등장. 4분 이후에도 일반 적 웨이브는 계속된다. |
| `5:00` | 기존 일반 적·엘리트·적 탄환을 정리하고 보스 1기 등장. |
| `5:20` | 보스가 살아 있으면 해당 지점의 일반 적 목록에서 앞의 두 기종을 한 기씩 호출한다. 한 기종만 있으면 같은 기종 2기를 호출한다. |
| 보스 정화 | 클리어 및 결과 표시. 첫 클리어면 다음 입장 지점 해금 |
| HP 0 또는 보스 정화 시간 초과 | 즉시 귀환 및 실패 결과 표시 |

일반 웨이브는 5분에 보스가 등장할 때까지 진행한다. 보스를 정화하면 소환된 적을 함께 정리하고 전투를 끝낸다. 보스전에서도 실제 경과 시간은 기록하되 생존 시간 점수는 300점에서 고정한다. 일시정지 중에는 경과 시간, 소환 일정, 물약 이동과 스킬 지속 시간·재사용 시간이 함께 멈춘다. 동일 전투 갱신에서 HP 0과 보스 정화가 함께 발생하면 클리어 우선으로 처리하는 안을 적용한다.

### 난이도와 성장

| 지점 | 일반 웨이브 소환 간격 | 기본 보스 체력 | 정화 제한 |
| --- | ---: | ---: | --- |
| 1-1 | 약 3.28~3.40초 | 160 | 없음 |
| 1-2~2-3 | 약 2.95~3.34초 | 375~503 | 보스 등장부터 50초 |
| 3-1~4-3 | 약 2.56~3.01초 | 535~695 | 보스 등장부터 50초 |

- 출동 직후 첫 웨이브를 소환하고, 이후 표의 간격으로 다음 웨이브를 확인한다. 한 번에 나오는 적 수는 [일반 웨이브 출현 수와 회피 공간](#일반-웨이브-출현-수와-회피-공간)을 따른다.
- 1-1은 기본 5 HP·1발과 레벨 1 펫으로 클리어할 수 있는 입문 지점이다. 1-2부터는 보스 체력을 지점마다 32씩 올린다. 기본 정화 펄스로 50초 내에 낼 수 있는 피해는 약 358이므로, 후속 지점은 입장 후 실제 전투에서 발사체 개수·피해량 강화 또는 펫 성장이 필요하다. 진행이 깊어지면 여러 강화를 조합한다.
- 무한 모드도 구역마다 시작 즉시 일반 적 무리가 등장한다. 보스전 시간 제한은 스테이지 모드의 1-2 이후에만 적용한다. 스테이지 모드에서 일반 적은 동시 18기까지 나온다. 일반 적과 엘리트는 새 묶음을 더한 화면 내 탄환 수가 48발을 넘으면 발사를 미룬다. 무한 모드의 동시 적 상한은 24기이며 일반 적과 엘리트의 발사에는 180발 상한을 적용한다. 두 모드에서 보스는 정해진 발사 간격을 유지한다.
- 스테이지 모드의 적 탄속은 1-1에서 기준의 70%로 시작해 지점마다 1.4%p, 공격 빈도는 1%p 높인다. 4-3에서는 각각 기준의 85.4%와 81%다. 일반 적의 체력은 지점당 기본 체력의 7.5%, 엘리트는 4.5%씩 높여 탄막 밀도보다 정화에 필요한 화력에서 난이도 차이를 만든다. 탄속 배율은 발사 시 속도와 가속 구간의 목표 속도에 모두 적용한다.
- 출전 펫은 일반 귀환이나 스테이지 클리어 시 정화한 적 1기당 경험치 1을 받는다. 다음 레벨 성장에 필요한 양까지만 쌓이며 출동을 중단하면 경험치를 받지 않는다. 마이룸에서 성장시킨 펫은 레벨 2·3·4에서 정화 펄스 피해량에 각각 15%·30%·45%를 더한다. 이 배율은 피해량 강화에 곱해서 적용하며, 레벨 4 이후에는 45%를 유지한다.
- 플레이테스트에서 기본 세팅의 1-1 완주율, 펫 성장 또는 발사체 강화 후 1-2의 정화 시간, 후반 웨이브의 회피 공간을 확인한다. 정화 제한 시간을 넘기면 귀환 결과와 사유를 표시하고, 귀환 점수 보상은 정상 지급한다.

#### 일반 웨이브 출현 수와 회피 공간

| 일반 적 패턴 | 웨이브당 출현 수 |
| --- | ---: |
| 일반 1 · 무탄 이동 | 10기. 작전 4에서는 12기. |
| 일반 2 · 팔각 방사 | 2기. 작전 4에서는 4기. |
| 일반 3 · 사각 방사 | 4기. 작전 3에서는 6기. |
| 일반 4 · 반원 이중탄 | 2기. 작전 4에서는 3기. |
| 일반 5 · 조준 가속 연사 | 3기 |
| 일반 6 · 원형 방사 | 3기 |
| 일반 7 · 조준 세 갈래 | 4기 |
| 일반 8 · 하향 가속 연사 | 5기 |

- `1-1`은 순찰기 10기로 시작한다. `2-1`은 운반기 10기와 경비기 4기가 번갈아 나온다. `3-1`은 장갑 작업기 5기와 잔디 관리기 6기가 교대한다. `4-2`는 분사기·원형 방사형 장갑 작업기·중계기가 각각 3기씩 차례로 나온다.
- 무탄 편대는 화면 한쪽의 인접한 두 경로에 절반씩 배치하고, 각 경로 안에서는 앞뒤 간격을 둔다. 다음 무탄 웨이브는 반대쪽에서 들어온다. 추적형 운반기는 두 줄의 출발 시점을 어긋나게 해 한꺼번에 모이지 않도록 한다. 사격형이 남아 있을 때는 탄을 피할 수 있는 쪽을 비워 둔다.
- 사격형 일반 적은 화면에 합계 6기까지 남을 수 있으며, 그중 일반 4·6은 합계 3기까지다. 첫 공격 시작을 적마다 최소 0.6초씩 벌리고, 이후에는 한 번에 최대 2기까지 공격을 진행한다. 일반 4·6은 한 기씩 차례로 발사하며, 다음 기체는 앞선 방사탄이 플레이어의 이동 구간을 지난 뒤 쏜다. 엘리트가 일반 4·6을 발사할 때도 같은 순서 규칙을 적용한다.
- 웨이브 전체가 출현 상한에 들어갈 자리가 생기면 같은 기종의 웨이브를 배치하고 순서를 넘긴다. 자리가 없으면 다음 소환 시점에 다시 확인한다. 엘리트가 호출한 작업기와 보스 증원도 동시 출현 상한에 포함한다.
- 회피 공간은 탄환 수와 적의 이동 경로를 함께 확인한다. `4-1`에서 무탄 적 12기와 사격형이 겹칠 때, `3-1`에서 일반 사격형이 6기 나올 때, `4-2`에서 넓게 퍼지는 탄막을 3기가 차례로 쏠 때 일반 이동이나 `Shift`로 빠져나갈 경로가 하나 이상 이어져야 한다. 통로가 닫히면 출현 위치와 발사 시차를 먼저 조정한다.

적 탄환은 논리 폭 14px, 원형 충돌 반지름 6px를 사용한다. 레이저는 예고 중 피격 판정이 없고, 발사 중 표시된 띠에 피격 판정을 적용한다. 일반 적과 엘리트는 발사 시점마다 묶음 단위로 탄환 상한을 확인한다. 보스의 연사와 순차 발사는 화면의 탄환 수와 관계없이 정해진 간격과 발수를 유지한다. `4-3` 보스가 처음 HP 50% 이하에 도달하면 진행 중인 공격과 화면의 적 탄환을 정리하고 0.8초 뒤 후반 순서를 시작한다.

플레이테스트에서는 `1-1`을 기본 화력으로 정화할 수 있는지, `2-2` 레이저의 예고 범위와 실제 피격 범위가 일치하는지, `3-1`에서 탄이 방향을 바꾼 뒤 회피할 수 있는지 확인한다. `3-3`과 `4-3`에서는 탄이 많이 남아 있어도 보스가 정해진 간격으로 순차 발사하는지, 증원이 겹쳐도 `Shift`로 통과할 틈이 남는지 확인한다.

### 무한 모드

- `4-3` 클리어 후 모드 선택 즉시 정기 출동으로 시작한다.
- 초기 배경은 사파리다. 각 구역 진입 후 1·2·3·4분에 엘리트가 등장한다. 5분에 일반 웨이브를 마감하고 구역 보스가 등장한다. 보스가 등장하면 기존 적과 적 탄환을 정리한다. 보스가 20초 동안 살아 있으면 해당 지점의 일반 적 목록에서 앞의 두 기종을 한 기씩 호출한다. 한 기종만 있으면 같은 기종 2기를 호출한다. 보스를 정화하면 다음 구역의 소환 일정을 0분부터 시작한다. 누적 생존 시간은 이어진다. 사파리 `1-3` → 숲 `2-3` → 정비 구역 `3-3` → 허브 `4-1`의 일반 적·엘리트·보스 편성을 가져와 네 구역을 순환한다. 웨이브당 출현 수와 사격형 동시 출현 규칙을 함께 적용한다. 구역 전환 시 남은 적 탄환을 정리한다.
- 진행에 따라 적 체력, 조합, 탄막 밀도를 조정한다. 일반 적과 엘리트의 탄환 상한과 보스 패턴의 발사 간격은 성능과 회피 가능성을 기준으로 조정한다. HP가 0이 되면 출동이 끝나고 이번 주 랭킹 집계 대상이 된다.

### HP와 회복

- 생존 상태는 HP 하나로 관리한다. 기본 최대 HP는 **5**이며 매 판 강화가 반영된 최대 HP로 시작한다. 일반 피격은 1 HP를 차감하고 기존 피격 후 무적 시간 2초를 적용한다.
- 두 모드에서 엘리트를 정화하면 그 자리에 물약 1개를 떨어뜨린다. 물약은 아래로 이동하며 플레이어가 닿으면 소모되어 **1 HP**를 회복한다. 최대 HP에서 닿으면 물약만 소모되고, 화면 아래를 벗어난 물약은 제거한다.
- 회복 수단은 물약과 펫의 체력 회복 스킬이다. 둘 다 최대 HP까지만 1 HP를 회복한다. HP가 0이면 전투를 종료한다.

### 점수와 셀 보상 초안

| 항목 | 계산식 및 규칙 |
| --- | --- |
| 생존 시간 점수 | 전투 1초당 1점, 초 단위 내림. 스테이지 모드는 최대 300점, 무한 모드는 실제 전투 시간 전체를 반영한다. 조작 안내와 일시정지 시간은 전투 시간에서 제외한다. |

| 최종 점수 | `생존 시간 점수 + 정화 점수` |
| 점수 보상 | `최종 점수 ÷ 25`를 내림한 셀. 스테이지 실패·클리어 및 무한 모드의 정상 종료에 지급한다. |
| 스테이지 클리어 보상 | 각 지점의 보스를 정화할 때마다 아래 고정 보상을 점수 보상에 더한다. |
| 출동 중단 | 중단으로 표시한다. 보상 지급과 랭킹 등록 대상에서 제외한다. |

| 작전 | 첫 번째 지점 | 두 번째 지점 | 세 번째 지점 |
| --- | ---: | ---: | ---: |
| 작전 1 | `1-1` 40셀 | `1-2` 50셀 | `1-3` 60셀 |
| 작전 2 | `2-1` 70셀 | `2-2` 80셀 | `2-3` 90셀 |
| 작전 3 | `3-1` 100셀 | `3-2` 110셀 | `3-3` 120셀 |

- `1-1`에서 4분 동안 50기를 정화하고 실패하면 `240 + 500 = 740점`으로 **29셀**을 받는다.
- `1-1`에서 보스를 포함해 110기를 정화하고 5분 40초에 클리어하면 `300 + 1,100 = 1,400점`이다. 점수 보상 56셀과 클리어 보상 40셀로 **96셀**을 받는다.

## 4. 능력치 강화

뱀파이어 서바이버즈의 출전 전 강화 화면을 시각적 참고로 삼는다. 왼쪽은 항목 카드 그리드, 오른쪽은 선택한 항목의 설명과 구매 영역으로 구성한다. 카드에 아이콘·이름·현재 단계·최대 단계를 표시하고 상세 영역에 **현재 효과 → 다음 단계 효과**, 비용, 보유 재화, 강화 버튼을 표시한다. 잔액 부족, 최대 단계, 저장 실패를 구분해서 표시한다. 카드 개수가 늘어나면 그리드 안에서 스크롤한다.

| 항목 | 전투 효과와 단계 | 단계별 비용 초안 (셀) |
| --- | --- | --- |
| 발사체 개수 | 기본 1발, 단계당 +1발, 최대 2단계. 플레이어 중심 기준 좌우 대칭 배치 | 120 / 300 |
| 피해량 | 정화 펄스 1발의 피해량이 기본 대비 단계당 +10%, 최대 5단계 | 60 / 100 / 150 / 220 / 320 |
| 발사체 크기 | 표시와 충돌 범위가 기본 대비 단계당 +10%, 최대 5단계 | 50 / 80 / 120 / 180 / 260 |
| 체력 | 기본 최대 5 HP, 단계당 +1 HP, 최대 3단계 | 80 / 150 / 280 |

강화는 셀을 소모하며 다음 출동부터 두 모드에 적용한다. 성공 시 셀 잔액과 단계를 함께 갱신한다. 항목마다 ID·이름·아이콘·설명·단계별 효과와 비용을 정의해 UI에서 동일한 카드로 표시한다. 새 효과는 전투 쪽 적용 규칙을 추가한다.

## 5. 펫 설정과 스킬

1. 보유 펫 목록을 표시하고 현재 출전 펫을 강조한다. DB 연동 전에는 기존 클라이언트 펫 데이터를 사용한다. 연동 후에는 DB에 저장된 로그인 유저의 보유 펫을 목록에 표시한다.
2. 펫을 클릭하면 상세에 이름·이미지·고유 스킬 효과·쿨타임, `장착` 버튼과 펫 장비 칸이 표시된다. 목록에서 살펴보는 펫과 출전 펫은 별도 상태다. `장착`을 누르면 출전 펫 한 마리를 교체하고 저장한다.
3. 장비 칸을 누르면 해당 슬롯과 호환되는 보유 장비를 표시한다. 장비 선택 시 효과를 미리 보여주고, `장착` 또는 `해제`를 누르면 그 펫의 슬롯을 갱신한다. 장비가 없으면 빈 상태를 표시한다. 초안은 펫당 슬롯 1개, 장비 1개를 동시에 한 펫에만 장착하는 규칙이다. 장비 교체 규칙과 획득처는 확정 후 적용한다.
4. 입장 시 출전 펫·장비·강화 단계의 전투 값을 확정한다. 스킬 버튼은 준비·효과 적용 중·재사용 대기 상태와 남은 시간을 표시한다. 장착 성공은 목록의 출전 표시로 확인하고, 저장 실패 때 안내를 표시한다. 모든 스킬의 재사용 대기 시간은 **60초**이며 성공적으로 발동한 시점부터 흐른다.

| 고유 스킬 | 적용 범위 | 프로토타입 수치 |
| --- | --- | --- |
| 보호막 | 짧은 시간 플레이어 피격을 막는다. 기존 보호막 동작을 재사용한다. | 3초 지속 |
| 전체 탄환 지우기 | 발동 순간 전투 영역 내 적 탄환을 즉시 제거한다. 이후 탄환은 계속 생성된다. | 즉시 |
| 체력 회복 | 현재 HP를 즉시 회복한다. 체력이 가득 차 있으면 발동과 재사용 대기 모두 시작하지 않는다. | 1 HP |
| 공격속도 증가 | 일정 시간 자동 발사 빈도를 증가시킨다. | +30%, 5초 지속 |

펫 데이터가 고유 스킬 ID를 가리키게 하고, 공통 HUD는 스킬 이름·아이콘·시간 상태를 읽어 표시한다. 이후 펫과 스킬을 추가할 때 기존 선택 화면을 재사용한다. 네 가지 스킬을 어떤 펫에 배정할지와 장비가 스킬·전투 수치 중 어디에 영향을 줄지는 별도 결정한다.

## 6. 저장과 주간 랭킹

| 데이터 | 초기 클라이언트 저장 | DB 연동 후 |
| --- | --- | --- |
| 보유 펫·출전 설정 | 기존 펫 데이터와 로컬 장착 상태를 사용한다. | 보유 펫 목록을 로그인 유저의 DB 데이터에서 조회한다. 장착·장비의 계정 저장 범위는 별도로 정한다. |
| 강화·셀·스테이지 진행 | 강화는 항목 ID별 단계로 저장한다. 셀 잔액, 클리어한 지점, 지점별 최고 점수도 로컬에 기록한다. | 강화·진행 저장은 우선 로컬에 둔다. 향후 이전을 위해 저장 데이터에 버전을 두고 화면과 전투는 저장 위치에 직접 의존하지 않게 한다. |
| 무한 모드 결과 | 현재 브라우저의 무한 모드 기록으로 이번 주 순위를 미리 확인한다. 화면에 `이 브라우저의 기록`으로 표시한다. | 정상 종료한 무한 모드 점수를 DB에 기록한다. 필수 정보는 출동 ID, 유저 ID, 점수, 서버가 기록한 완료 시각이다. 닉네임은 유저 정보에서 조회한다. |

- **조회.** 메인에서 `랭킹`을 열면 초기에는 로컬 기록을 읽고, DB 연동 후에는 서버에 이번 주 무한 모드 기록을 요청한다. 점수 내림차순으로 표시한다. 초안은 유저별 주간 최고 점수 한 건을 집계하며 동점이면 먼저 달성한 기록을 위에 표시한다. 이번 주 기록이 없으면 빈 상태를 표시한다.
- **주간 초기화.** 초안 기준은 한국시간 월요일 `00:00`부터 다음 월요일 `00:00` 직전까지다. 출동을 끝낸 시각으로 집계 주를 정한다. 새 주에는 이전 주 기록이 순위에서 빠진다. 초기에는 클라이언트 시각, DB 연동 후에는 서버 시각을 사용한다.
- **결과 저장.** 출동 ID별로 결과와 셀 보상을 한 번만 반영한다. DB 전환 시에는 검증 가능한 새 출동부터 공용 랭킹에 집계한다. 서버의 결과 검증 방식과 계정 간 동기화 범위는 연동 단계에서 확정한다.

## 9. Aseprite 도트 이미지 제작 목록

### 제작 순서와 산출물

1. **`1-1` 시안.** 사파리 지도와 전투 배경, 제로·보이드 초상, 호버보드 탑승자와 추진광, 고양이와 부유 발판, 순찰기·엘리트·선두 순찰기, 기본 탄환과 물약을 먼저 그린다. 탑승자와 펫의 부유 이동을 확인한 뒤 체력·경고·보호막 아이콘과 효과를 붙여 시작 대화부터 결과까지 연결한다.
2. **전체 구역과 공용 UI.** 리코·자일로·코덱스 초상과 네이티의 상태별 스프라이트, 나머지 지도와 배경, 지점별 오브젝트, 적·보스 변형과 전용 이펙트, 메뉴·강화·스킬 아이콘과 공용 장비 아이콘을 제작한다. 구역이 달라져도 탄환, 물약, 플레이어의 피격 중심을 즉시 찾을 수 있는지 확인한다.
3. **원본과 게임 파일 내보내기.** 제작 원본은 `art/minigame/`에 `.aseprite`로 보관하고, 게임에서 쓰는 파일은 `client/public/assets/minigame/`에 둔다. 정적 이미지는 PNG, 애니메이션은 투명 PNG 스프라이트 시트와 Aseprite JSON으로 내보낸다. 프레임 태그는 용도에 맞춰 `idle`, `move`, `attack`, `cast`, `purified` 등을 사용하고 애니메이션 프레임의 기준점을 고정한다. 파일명에는 `map-01`, `boss-1-1`, `pet-cat-001`, `fx-shield`처럼 게임에서 찾기 쉬운 ID를 사용한다.

완료 기준은 1280×720 화면에서 도트 가장자리가 흐려지지 않고, 종스크롤 배경의 반복 경계가 보이지 않으며, 탄환·물약·경고를 색과 형태로 구별할 수 있는 상태다.

## 10. 스테이지 시작과 종료 대화

아래는 스토리 프레임워크의 역할을 반영한 게임용 임시 대사다. 한 줄에 화자 한 명을 표시한다. 보이드의 문구는 단말 메시지로 표시하고, 네이티와 동행 펫은 표정·빛·움직임으로 반응한다. 동행 펫의 반응 연출은 현재 출전 펫 스프라이트를 사용한다. [인물 배치 프레임워크](./doroland-minigame-story-framework.md#10-등장인물-배치-프레임워크)

- **시작 대화.** 지도에서 `입장`을 누른 직후 표시한다. 마지막 대사를 넘기면 전투를 시작하고, `1-1`은 먼저 조작 안내로 넘어간다. 전투 시간은 적 소환이 시작될 때부터 계산한다.
- **클리어 대화.** 보스 정화 순간에 전투와 점수 산정을 끝내고, 마지막 대사 뒤에 결과 화면을 연다. `4-3`의 클리어 대화가 사건의 결말을 맡고, 첫 클리어 결과에서 무한 모드 해금을 안내한다.
- **귀환과 재도전.** HP가 0이면 보이드 단말에 “위험 한계 도달. 자동 귀환을 시작합니다.”를 띄운 뒤 실패 결과를 표시한다. 중단 시에는 바로 중단 결과를 표시한다. 재도전에서는 시작·종료 대화를 다시 보거나 `건너뛰기`로 넘길 수 있다.

### 작전 1. 낯선 순찰

| 지점 | 시작 대화 | 클리어 대화 |
| --- | --- | --- |
| `1-1` 외곽 순찰로 | **제로** “호버보드 준비됐어? 네 펫도 발판에 올라탔네. 저 순찰기, 아까도 이 표지판 앞을 지났어.”<br>**보이드 단말** “반복 경로 확인. 첫 임무는 선두 순찰기를 정화하고 입구를 확보하는 것입니다.” | **제로** “좋아, 이번엔 표지판 앞에서 멈췄어. 이제 안전하게 지나갈 수 있겠다.”<br>**보이드 단말** “관리 초원에서도 같은 시간 간격의 방향 전환을 감지했습니다.” |
| `1-2` 관리 초원 | **제로** “한 대가 방향을 틀면 저쪽 기계도 딱 맞춰 돌아. 신호를 같이 받는 걸까?”<br>**보이드 단말** “초원 경비기의 동작 기록을 확보하면 명령이 들어온 시각을 대조할 수 있습니다.” | **보이드 단말** “전환 시각 일치. 사파리 관제소에도 같은 시각의 수신 기록이 있습니다.”<br>**제로** “그럼 관제소에서 어떤 명령이 들어왔는지 확인해 보자.” |
| `1-3` 사파리 관제소 | **제로** “순찰 대장이 관제소 문을 막고 있어. 저 기계가 길을 비켜주면 기록을 확인할 수 있겠어.”<br>**보이드 단말** “관제소 접속 대기. 순찰 대장의 상태를 안정시켜 주세요.” | **보이드 단말** “현재 운영표에 없는 옛 순찰 명령을 발견했습니다. 같은 명령 형식이 숲 관리로에서도 수신됐습니다.”<br>**제로** “리코에게 기록을 보냈어. 이번에는 숲 쪽으로 가자.” |

### 작전 2. 어긋난 숲의 박자

| 지점 | 시작 대화 | 클리어 대화 |
| --- | --- | --- |
| `2-1` 숲 관리로 | **리코** “사파리 기록과 비교해 봤어. 이쪽 운반기는 분기 밸브가 열리기도 전에 출발하고 있어.”<br>**코덱스** “물을 기다리는 나무가 있다. 먼저 관리로를 열어라.” | **리코** “운반 순서는 맞췄어. 이제 분기점의 밸브가 언제 열리는지 확인할 수 있겠다.”<br>**코덱스** “분기점에 네이티가 있다. 빛이 급해지면 먼저 주위를 살펴라.” |
| `2-2` 급수 분기점 | **네이티 연출** 노란빛이 짧게 깜빡이고 분기 밸브에서 물러난다.<br>**코덱스** “저 분사기가 움직일 때마다 네이티가 물러난다. 노즐이 돌아가는 방향을 살펴라.”<br>**리코** “분기 밸브기를 정화하면 어느 쪽에서 다시 명령을 보내는지 볼 수 있어.” | **네이티 연출** 하늘빛이 일정해지고 밸브 곁에 천천히 다가간다.<br>**코덱스** “물이 낮은 뿌리까지 닿는군.”<br>**리코** “급수는 돌아왔어. 제어 신호가 하모니아 연결 관리로 쪽에서 되돌아오고 있어.” |
| `2-3` 하모니아 연결로 | **리코** “급수 관리기가 분기점으로 같은 명령을 되돌려 보내고 있어. 정화하면 다음 전송 지점을 확인할 수 있어.”<br>**코덱스** “숲의 물길은 내가 지켜보마. 관리기를 살펴라.” | **리코** “경로를 찾았어. 신호가 보조 제어망을 타고 관람차 정비 구역까지 이어져.”<br>**코덱스** “이쪽 급수는 안정됐다. 나는 숲에 남아 물길을 살피겠다.” |

### 작전 3. 되풀이되는 명령

| 지점 | 시작 대화 | 클리어 대화 |
| --- | --- | --- |
| `3-1` 관람차 정비로 | **자일로** “재개장 때 사용한 정비 기록을 공유했습니다. 방금 정화된 기계가 같은 지시를 다시 받은 시각도 표시해 뒀어요.”<br>**리코** “정비 지휘기를 안정시키면 장비가 받은 명령과 정비 기록을 맞춰볼 수 있어.” | **보이드 단말** “정화 후 동일 명령 재수신 확인. 첫 수신 시각은 자재 이송장의 송신 기록과 일치합니다.”<br>**자일로** “그 기록도 함께 열어 두겠습니다. 중계기부터 확인해 주세요.” |
| `3-2` 자재 이송장 | **보이드 단말** “증원 호출 감지. 송신 위치는 이송장 안쪽 중계기입니다.”<br>**리코** “중계기가 작업기를 계속 부르고 있어. 정화한 뒤 신호가 어디서 들어왔는지 거슬러 올라가자.” | **보이드 단말** “증원 호출 중단. 중계기 직전의 신호 경로는 크레인 작업장입니다.”<br>**리코** “크레인 쪽 로그가 남아 있다면 이 명령을 처음 보낸 장치를 찾을 수 있어.” |
| `3-3` 크레인 작업장 | **자일로** “크레인 제어기에 송신 원본 주소를 남기는 기능이 있습니다. 장비가 안정되면 제가 마지막 기록을 열겠습니다.”<br>**리코** “크레인이 움직이는 방향을 봐. 안전한 틈이 열리면 정화 펄스를 보내자.” | **보이드 단말** “송신 원본 주소 확인. 보조 제어 허브의 옛 동기화 장치입니다.”<br>**자일로** “허브 도면을 팀에 공유했습니다. 중앙 장치까지 가는 동안 보조 송신부터 차단하죠.” |

### 작전 4. 마지막 동기화

| 지점 | 시작 대화 | 클리어 대화 |
| --- | --- | --- |
| `4-1` 허브 진입로 | **보이드 단말** “허브 입구에 사파리 순찰기와 숲 운반기가 모이고 있습니다. 진입로를 지도에 표시했습니다.”<br>**제로** “펫이 벌써 고개를 돌렸어. 서두르지 말고 안전한 쪽부터 길을 열자.” | **보이드 단말** “진입로 확보. 송신 제어실 출입이 가능합니다.”<br>**제로** “좋아, 너희가 길을 열어줬으니 리코와 자일로도 제어실로 들어갈 수 있어.” |
| `4-2` 송신 제어실 | **자일로** “좌우 송신 모듈을 모두 안정시키면 제가 보조 송신을 차단하겠습니다.”<br>**리코** “두 모듈이 번갈아 신호를 보내고 있어. 마지막 송신 경로가 이 방을 지나가.” | **자일로** “보조 송신을 차단했습니다. 중앙 장치의 연결도 확인했어요.”<br>**리코** “이제 중앙 방어기만 정화하면, 반복 명령을 보내는 회선을 끊을 수 있어.” |
| `4-3` 중앙 동기화실 | **리코** “방어기가 계속 같은 명령을 받고 있어. 네 펫이 반응하면 정화할 틈을 봐.”<br>**자일로** “두 분이 방어기를 안정시키는 동안 차단을 준비하겠습니다. 정화 신호가 오면 바로 회선을 끊을게요.” | **보이드 단말** “방어기 정화 완료. 반복 송신이 종료되었습니다.”<br>**자일로** “네 구역의 기록과 차단 절차를 공개하겠습니다. 다음 점검부터 함께 확인해요.”<br>**네이티 연출** 허브 지도 위에서 흰빛이 부드럽게 번진다.<br>**코덱스** “숲의 물길이 평온하다. 이제 다시 함께 돌볼 수 있겠군.”<br>**제로** “돌아온 걸 환영해. 오늘은 펫한테도 수고했다고 해 주자!” |
