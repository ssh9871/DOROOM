### Docker 시작 오류 원인

2026-10-20 12:13:29 KST의 Docker backend 로그에서 Secrets Engine 초기화 중 `engine.sock`을 `engine.sock.stale`로 바꾸는 작업이 “The file cannot be accessed by the system” 오류로 실패했고, 시작 오류 창이 열린 기록을 확인했다. 후속 재시작에서는 Docker Desktop·Docker API·WSL2가 running 상태로 복구됐다. 데이터·볼륨 삭제나 초기화는 수행하지 않았다.

샌드박스 안에서는 별도로 Docker named pipe 및 WSL/로컬 소켓 접근이 거부됐다. 실제 Windows 환경의 승인된 명령 실행으로 엔진 응답과 빌드·HTTP 검증을 완료했다.

### 한계와 미검증

- JSON은 빌드에 포함되는 고정 기본 데이터다. 장착 ID만 브라우저 localStorage에 보관하며 JSON 파일 직접 수정·서버/DB·계정 간 동기화는 없다.
- 호감도와 배고픔은 100 고정, 방어막은 데이터만 존재한다. 펫 육성·능력 발동·다른 메뉴 기능은 구현하지 않았다.
- 기존 고양이 GLB는 애니메이션 트랙이 없는 간단한 모델이다. 위치·회전으로 추종하며 전용 걷기 애니메이션은 제작하지 않았다.
- 저장소 차단은 자동 검사로 확인했다. 실제 브라우저의 저장소 권한 차단, 모델 네트워크 실패 강제 주입, WebGL 미지원 기기는 재현하지 않았다.
- 빠른 장착 반복과 로딩 중 방 이탈은 브라우저에서 확인했지만 네트워크 지연을 강제로 주입한 경쟁 조건 검사와 장시간 메모리 프로파일링은 하지 않았다.
- 평평한 빈 방의 직접 추종만 지원한다. 장애물 길찾기·모바일 터치 조작·다른 브라우저/GPU 전체 호환성은 검증하지 않았다.
- 마이룸 청크 약 1.16 MB(비압축)의 기존 대형 번들 경고가 남는다. 마이룸 진입 시 동적으로 로드한다.

## 자동 검사 범위

`client/src/room/movement.test.ts`를 Node.js 기본 TypeScript 실행으로 검사한다. 별도 테스트 라이브러리는 사용하지 않는다.

1. 직선과 대각선 이동 거리 동일.
2. 지면에서 점프 시작.
3. 공중에서 추가 점프 불가.
4. 지면 착지와 수직 속도 초기화.
5. 직사각형 방 경계 제한.
6. 긴 프레임 시간에 의한 순간이동 방지.

키 누름 반복에 의한 점프는 입력 처리에서 `event.repeat`을 무시한다. 자동 검사는 순수 이동 계산을 대상으로 하며 실제 키 입력·화면 전환은 브라우저에서 별도로 확인했다.
