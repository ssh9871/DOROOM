# 프론트엔드 데모 검증

검증일: 2026-10-19. Windows의 Docker Desktop Linux 컨테이너와 앱 내 Chromium 브라우저(1280×720)에서 확인했다.

## 통과

- `docker compose up --build -d`: 의존성 설치, 이동 계산 검사 6개, TypeScript 검사, Vite 빌드 및 nginx 실행 성공.
- `docker compose config --quiet`: Compose 설정 정상. 서비스는 `web` 하나이며 `127.0.0.1:8080 → 80`으로 연결.
- HTML, 제공 아바타 복사본, 대체 로봇 GLB, 대체 고양이 GLB, 아바타·펫 PNG의 HTTP 200 응답 확인.
- 대시보드의 세 이미지 모두 실제 로딩 완료. 마이룸·미니게임 외의 서비스 요소에는 동작 없음.
- 미니게임 카드 한 개 및 비활성 플레이하기 확인. 클릭·Enter 입력 후 화면과 동작 변화 없음.
- 제공 로봇 및 직접 생성한 고양이 GLB의 실제 WebGL 렌더링 확인.
- 마이룸 진입 후 로봇 한 개, 바닥·벽·이름표·장식 포털 표시 확인.
- 실제 WASD 네 방향 이동, 카메라 추적, Space 점프 확인. 점프 화면을 별도로 저장.
- 나가기 확인 팝업의 아니요 선택 시 마이룸 유지, 네 선택 시 메인 복귀 확인.
- 메인 복귀 후 Canvas 0개 확인. 빠른 진입·뒤로 가기 후에도 Canvas 0개, 앞으로 가기로 재입장 확인.
- 정상 경로 검증 중 브라우저 콘솔 오류·경고 없음.
- `server/`는 기존 빈 `.gitkeep` 네 개만 유지.

## 자동 검사 범위

`client/src/room/movement.test.ts`를 Node.js 기본 TypeScript 실행으로 검사한다. 별도 테스트 라이브러리는 사용하지 않는다.

1. 직선과 대각선 이동 거리 동일.
2. 지면에서 점프 시작.
3. 공중에서 추가 점프 불가.
4. 지면 착지와 수직 속도 초기화.
5. 직사각형 방 경계 제한.
6. 긴 프레임 시간에 의한 순간이동 방지.

키 누름 반복에 의한 점프는 입력 처리에서 `event.repeat`을 무시한다. 자동 검사는 순수 이동 계산을 대상으로 하며 실제 키 입력·화면 전환은 브라우저에서 별도로 확인했다.

## 한계와 미검증

- 원본 고양이 GLB의 외부 텍스처가 없어 블록형 대체 고양이를 생성했다. 원본 파일은 그대로다.
- 제공 로봇은 정상 로딩되어 대체 로봇으로 자동 전환하는 실패 경로는 실제 브라우저에서 강제 재현하지 않았다. 대체 GLB의 파일 구조와 HTTP 응답은 확인했다.
- WebGL 미지원 기기에서의 오류 안내, 고의 네트워크 차단·손상 파일 오류 경로는 실제 기기에서 재현하지 않았다.
- 엔진·이벤트 정리는 코드와 화면 재진입으로 확인했으며 장시간 메모리 프로파일링은 하지 않았다.
- Babylon.js 마이룸 청크가 약 1.12 MB(비압축)여서 Vite의 500 kB 경고가 발생한다. 마이룸 진입 시 동적으로 로드하며, 메인 진입에는 해당 엔진 청크를 요청하지 않는다. 별도 번들 최적화는 하지 않았다.
- 모바일 터치 조작, 모든 브라우저·GPU의 호환성, 실제 게임·펫 기능은 이번 검증 범위에 포함하지 않는다.

기존 `hello-world.png`는 최초 환경 구축 때의 기록이며 현재 화면은 위 새 캡처를 기준으로 한다.
